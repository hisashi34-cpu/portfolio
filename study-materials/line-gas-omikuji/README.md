# LINE × GAS おみくじボット（勉強会教材）

シンプル版のおみくじチャットボットを、LINE Messaging API と Google Apps Script だけで作る勉強会用の教材です。**無料枠で運用可能**。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `Code.gs` | GASに貼り付けるコード一式 |
| `HANDBOOK.md` | LINE登録〜デプロイまでのステップ手順書 |
| `TROUBLESHOOTING.md` | よくあるつまずきポイントと対処法 |

## 進め方の目安（90分）

1. 導入・全体像説明（10分）
2. HANDBOOK の STEP 1〜2 を全員で進める（25分）
3. STEP 3〜5 を進める（30分）
4. 動作確認＆発展課題（25分）

つまずいた人が出たら `TROUBLESHOOTING.md` を参照。

## 完成イメージ

ユーザー: 「こんにちは」
Bot: 「今日の運勢は【中吉】です！」
